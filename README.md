# ratelimit — ограничение частоты запросов

Два классических алгоритма и декоратор для защиты функций и эндпоинтов.

| Алгоритм | Как работает | Когда использовать |
|---|---|---|
| **Token Bucket** | Ведро на N токенов пополняется со скоростью R/сек, запрос тратит один токен | Нужно разрешать короткие всплески |
| **Sliding Window Log** | Хранит время запросов за последнее окно | Нужен точный лимит «не больше N за T секунд» |

```python
from ratelimit import SlidingWindow, rate_limited

@rate_limited(SlidingWindow(limit=5, window_sec=60), key_func=lambda user_id: user_id)
def send_otp(user_id): ...
```

Лимиты считаются отдельно для каждого клиента. Часы передаются как зависимость, поэтому тесты не используют `sleep` и выполняются мгновенно.

**Масштабирование:** для нескольких инстансов сервиса состояние выносится в Redis (`INCR` + `EXPIRE` или Lua-скрипт для атомарности).
